# Gemini Cookbook Learning Strategy

**Created**: 2025-11-18
**Goal**: Master Gemini API to build AI code agents

## Repository Setup
- **Main Branch**: Keep clean, synced with upstream
- **Dev Branch**: Personal learning, experiments, notes
- **Fork Status**: Working in local clone

## Learning Path

### Phase 1: Foundation (Week 1)
- [ ] Authentication - Set up API access
- [ ] Get Started - Basic prompting and multimodal
- [ ] Counting Tokens - Resource management
- [ ] Function Calling - Agent building basics

### Phase 2: Core Features (Week 2)
- [ ] Code Execution - Python generation
- [ ] Grounding - Google Search, Maps integration
- [ ] File API - Document processing
- [ ] Embeddings - Semantic search

### Phase 3: Advanced Agent Building (Week 3-4)
- [ ] Barista Bot Agent - Function calling patterns
- [ ] Browser as Tool - Web interaction
- [ ] Live API - Real-time multimodal
- [ ] Batch Mode - Efficient processing

## AI Code Agent Ideas

### Target Projects
1. **Code Review Agent**
   - Analyze PRs, suggest improvements
   - Check for bugs, security issues
   - Generate test cases

2. **Documentation Agent**
   - Auto-generate docs from code
   - Keep docs in sync with codebase
   - Answer questions about codebase

3. **Refactoring Agent**
   - Identify code smells
   - Suggest modernization
   - Apply design patterns

## Key Technologies to Integrate
- **Gemini API** - Core intelligence
- **Function Calling** - Tool use
- **Code Execution** - Dynamic analysis
- **Grounding** - Up-to-date information
- **Embeddings** - Code search
